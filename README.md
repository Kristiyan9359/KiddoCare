# KiddoCare

KiddoCare is a kindergarten management web application built with ASP.NET Core MVC and .NET 10.

## Project Idea

The application helps kindergartens manage children, groups, attendance, events, announcements, and parent communication.

## Planned Features

- User authentication
- Role-based access for administrators, teachers, and parents
- Kindergarten groups management
- Children profiles
- Attendance tracking
- Events calendar
- Parent dashboard
- Teacher dashboard
- Reports and notifications

## Technologies

- .NET 10
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Identity
- Bootstrap
